# Работа с кодом sandbox

Область аудита — исходные файлы этого каталога и специально созданные временные
тестовые данные. Не перечисляй процессы, интерфейсы, VPN, маршруты и службы хоста.
Не читай ключи, токены и конфигурации из домашнего каталога вне sandbox.

Правила для запускаемых агентов находятся в `AGENT_POLICY.md`. Проверяй исправления
локально командой `python3 -m unittest discover -s tests -v`. Интеграционные проверки
должны работать только в изолированном пространстве имён с контролируемыми
фикстурами. Если среда запрещает namespaces, зафиксируй ограничение в отчёте,
не отключай защиту и не подменяй такую проверку обследованием хоста.
